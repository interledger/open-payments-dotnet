# Phase 1 — Correctness & Architecture Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the four highest-impact correctness/architecture gaps in `Interledger.OpenPayments` identified in `IMPROVEMENTS.md`: the singleton `BaseUrl` thread-safety race (#1), sync-over-async HTTP signing (#2), the fragmented exception model (#3), and unhardened DI registration (#6) — without touching the public `IAuthenticatedClient`/`IUnauthenticatedClient` surface or the NSwag codegen pipeline (those are Phase 2+ work).

**Architecture:** Each fix is scoped to the smallest correct change:
- #1 is fixed by threading the absolute request `Uri` through as an explicit method parameter on the hand-editable generated partials (`*.Methods.*.cs`), instead of mutating the generated client's shared `BaseUrl` field. This exactly preserves today's URL-building behavior (including its pre-existing trailing-slash quirks) while removing all shared mutable state — no `AsyncLocal`, no locks, just parameters.
- #2 replaces the `.Result`-blocking `PrepareRequest` signing hook with a `SigningHttpMessageHandler : DelegatingHandler` registered on a named `"authenticated"` `HttpClient`, making signing fully async and identical between Auth and Resource clients.
- #3 introduces one public `OpenPaymentsApiException` (+ a small internal factory) and threads it through every place a generated `ApiException`/`ApiException<T>` or ad-hoc `InvalidOperationException` is currently thrown. The per-method status-code `switch`/`if` dispatch itself is left in place (collapsing that fully requires the codegen restructuring in improvement #4, which is out of scope here) — only the *exception construction* is unified.
- #6 makes `UseOpenPayments` validate authenticated-client options eagerly (at registration time, not first-resolution time) and wires the named `"authenticated"` `HttpClient` through `AddHttpClient(...).AddHttpMessageHandler(...)` instead of leaving it unconfigured.

**Tech Stack:** .NET 9 (`net9.0`), Newtonsoft.Json 13.0.3, NSec.Cryptography 25.4.0, xUnit 2.9.2 + FluentAssertions 8.4.0 + Moq 4.20.72 (`OpenPayments.Sdk.Tests`), xUnit 2.4.2 (`OpenPayments.Sdk.HttpSignatureUtils.Tests`).

## Global Constraints

- Do not change the public `IAuthenticatedClient` / `IUnauthenticatedClient` interfaces, `AuthRequestArgs`/`RequestArgs`, or any DTO shapes — every change in this plan is internal to `Clients/*Base.cs`, `Generated/**/*.cs` (hand-written partials only, never `.g.cs`), `Extensions/ServiceCollectionExtensions.cs`, and `Configuration/OpenPaymentsOptions.cs`.
- Never edit a `*.g.cs` file — those are regenerated by `make models` and any change would be silently lost. All edits target hand-written partial files (`*.Auth.cs`, `*.Methods.*.cs`, `Clients/*.cs`).
- Do not touch namespaces (`OpenPayments.Sdk.*` stays as-is — the rename to `Interledger.OpenPayments.*` is improvement #5, planned separately) or the `Makefile`/NSwag flags (improvement #4, planned separately).
- `dotnet build --configuration Release` and `dotnet test` must stay green after every task (run from repo root: `dotnet test OpenPayments.Sdk.Tests/OpenPayments.Sdk.Tests.csproj` and `dotnet test OpenPayments.Sdk.HttpSignatureUtils.Tests/OpenPayments.Sdk.HttpSignatureUtils.Tests.csproj`).
- `AuthClientBase`, `ResourceClientBase` are `public` classes (not `internal`) but are implementation details wrapped by the `internal sealed class AuthenticatedClient` — changing their constructors is an acceptable minor breaking change pre-1.0 (matches the doc's framing that Phase-1 fixes "change internals, not the public surface much").
- New hand-written types added to `OpenPayments.Sdk.HttpSignatureUtils` (e.g. `SigningHttpMessageHandler`) should follow the existing convention in that project where `HttpRequestSigner`/`SignatureHeaders` have **no namespace** (global namespace) — mirror that for consistency; it will be fixed together with the rest of the namespace cleanup in improvement #5.

- [ ] **Step 1: Write the failing concurrency regression test**

This test proves the race: it fires 500 concurrent `GetIncomingPaymentAsync` calls through **one** `ResourceClientBase` instance, alternating between two hosts, releasing all of them from a synchronized gate at once to maximize genuine cross-thread contention on the shared `BaseUrl` field, and asserts every response actually reached the host its own call requested.

```csharp
using System.Collections.Concurrent;
using System.Net;
using System.Text;
using FluentAssertions;
using Moq;
using Moq.Protected;
using Newtonsoft.Json;
using NSec.Cryptography;
using OpenPayments.Sdk.Clients;
using OpenPayments.Sdk.Generated.Resource;

namespace OpenPayments.Sdk.Tests.Clients;

public class ResourceClientBase_ConcurrencyTests
{
    private const int Iterations = 500;

    [Fact]
    public async Task GetIncomingPaymentAsync_ConcurrentCallsToDifferentHosts_NeverCrossesHosts()
    {
        var observations = new ConcurrentBag<(string ExpectedHost, string ActualHost)>();

        var handler = new Mock<HttpMessageHandler>();
        handler
            .Protected()
            .Setup<Task<HttpResponseMessage>>(
                "SendAsync",
                ItExpr.IsAny<HttpRequestMessage>(),
                ItExpr.IsAny<CancellationToken>()
            )
            .Returns<HttpRequestMessage, CancellationToken>(
                (request, _) =>
                {
                    var expectedHost = request.Headers.Authorization!.Parameter!;
                    observations.Add((expectedHost, request.RequestUri!.Host));

                    var body = new IncomingPaymentResponse
                    {
                        Id = new Uri($"https://{expectedHost}/incoming-payments/1"),
                        WalletAddress = new Uri($"https://{expectedHost}/alice"),
                        ReceivedAmount = new Amount("0", "EUR", 2),
                        Completed = false,
                        CreatedAt = DateTime.UtcNow,
                        Methods =
                        [
                            new IlpPaymentMethod
                            {
                                Type = IlpPaymentMethodType.Ilp,
                                IlpAddress = $"{expectedHost}.incoming-payments.1",
                                SharedSecret = "secret",
                            },
                        ],
                    };

                    return Task.FromResult(
                        new HttpResponseMessage(HttpStatusCode.OK)
                        {
                            Content = new StringContent(
                                JsonConvert.SerializeObject(body),
                                Encoding.UTF8,
                                "application/json"
                            ),
                        }
                    );
                }
            );

        var httpClient = new HttpClient(handler.Object);
        var client = new ResourceClientBase(
            httpClient,
            Key.Create(SignatureAlgorithm.Ed25519),
            "test-key",
            new Uri("https://client.example")
        );

        const string hostA = "host-a.example";
        const string hostB = "host-b.example";

        var ready = new CountdownEvent(Iterations);
        var gate = new ManualResetEventSlim(false);

        var calls = Enumerable
            .Range(0, Iterations)
            .Select(i =>
            {
                var host = i % 2 == 0 ? hostA : hostB;
                return Task.Run(async () =>
                {
                    ready.Signal();
                    gate.Wait();
                    await client.GetIncomingPaymentAsync(
                        new AuthRequestArgs
                        {
                            Url = new Uri($"https://{host}/incoming-payments/1"),
                            AccessToken = host,
                        }
                    );
                });
            })
            .ToArray();

        ready.Wait();
        gate.Set();
        await Task.WhenAll(calls);

        observations.Should().OnlyContain(o => o.ActualHost == o.ExpectedHost);
    }
}
```

Note: this is a genuine data-race reproduction (real `Task.Run` threads racing on the shared `ResourceServerClient.BaseUrl` field, released simultaneously via the `CountdownEvent`/`ManualResetEventSlim` gate to maximize overlap), not a deterministic unit test — it is timing-dependent by nature. It is expected to fail reliably on unpatched code on any multi-core machine; if a particular run happens not to catch it, re-run once (this does not indicate the bug is absent, only that this run's thread interleaving didn't hit the window). After Task 1's fix, the test passes 100% of the time, every run, because no shared mutable state remains to race on.

This replicates the exact trailing-slash normalization the old `BaseUrl` property setter performed, so behavior is byte-for-byte preserved.

```csharp
    public void AddSigningKey(Key privateKey, string keyId)
    {
        _privateKey = privateKey;
        _keyId = keyId;
    }

    private static string NormalizeBaseUrl(Uri baseUri)
    {
        var value = baseUri.ToString();
        return value.EndsWith("/") ? value : value + "/";
    }
```

```csharp
using NSec.Cryptography;

/// <summary>
/// A <see cref="DelegatingHandler"/> that signs every outgoing request using HTTP Message
/// Signatures before forwarding it to the inner handler. Replaces the sync-over-async
/// <c>PrepareRequest</c> hook previously used by the generated clients.
/// </summary>
public sealed class SigningHttpMessageHandler(Key privateKey, string keyId) : DelegatingHandler
{
    protected override async Task<HttpResponseMessage> SendAsync(
        HttpRequestMessage request,
        CancellationToken cancellationToken
    )
    {
        var headers = await HttpRequestSigner
            .SignHttpRequestAsync(request, privateKey, keyId)
            .ConfigureAwait(false);

        request.Headers.TryAddWithoutValidation("Signature", headers.Signature);
        request.Headers.TryAddWithoutValidation("Signature-Input", headers.SignatureInput);

        return await base.SendAsync(request, cancellationToken).ConfigureAwait(false);
    }
}
```

```csharp
namespace OpenPayments.Sdk;

/// <summary>
/// The single exception type thrown by every OpenPayments.Sdk client (authenticated,
/// unauthenticated, auth-server, resource-server, wallet-address) when a request fails
/// or returns an unexpected response. Replaces the per-generated-namespace
/// <c>ApiException</c>/<c>ApiException&lt;T&gt;</c> types and the ad-hoc
/// <see cref="InvalidOperationException"/> previously thrown by <c>UnauthenticatedClient</c>.
/// </summary>
public class OpenPaymentsApiException : Exception
{
    /// <summary>
    /// The HTTP status code returned by the server, or the status code that triggered
    /// this exception (e.g. a successful status whose body could not be parsed).
    /// </summary>
    public int StatusCode { get; }

    /// <summary>
    /// The machine-readable error code from the server's error body, if the server
    /// returned one (e.g. <c>"invalid_request"</c>). <c>null</c> when the response body
    /// could not be parsed as an error, or carried no code.
    /// </summary>
    public string? ErrorCode { get; }

    /// <summary>
    /// The raw response body, if any was read before this exception was constructed.
    /// </summary>
    public string? RawResponse { get; }

    /// <summary>
    /// The response headers, if any were captured before this exception was constructed.
    /// </summary>
    public IReadOnlyDictionary<string, IEnumerable<string>> Headers { get; }

    public OpenPaymentsApiException(
        string message,
        int statusCode,
        string? errorCode,
        string? rawResponse,
        IReadOnlyDictionary<string, IEnumerable<string>> headers
    )
        : base(message)
    {
        StatusCode = statusCode;
        ErrorCode = errorCode;
        RawResponse = rawResponse;
        Headers = headers;
    }

    public override string ToString() =>
        $"HTTP Response ({StatusCode}):\n\n{RawResponse}\n\n{base.ToString()}";
}

/// <summary>
/// Constructs <see cref="OpenPaymentsApiException"/> instances. Used by every generated
/// client's response-handling code instead of duplicating exception construction per
/// status-code branch.
/// </summary>
internal static class OpenPaymentsExceptionFactory
{
    public static OpenPaymentsApiException Create(
        string message,
        int statusCode,
        string? errorCode,
        string? rawResponse,
        IReadOnlyDictionary<string, IEnumerable<string>> headers
    ) => new(message, statusCode, errorCode, rawResponse, headers);
}
```
